# Wind

Right rail **Broadcast → Wind**. Meteorological wind for the sea / vanes. Open-Meteo is [CC BY 4.0](https://open-meteo.com/) (ops, not a licensed on-air graphic).

---

## Controls

| Control | Default | What it does |
| --- | --- | --- |
| **from°** | 0 | Direction the wind is **from** |
| **kt** | 6 | Speed in knots |
| **hold** / **API** | follow API | **hold** = your numbers win (Open-Meteo will not overwrite). Button then reads **API** — press to follow Open-Meteo at origin (~10 min) |

Empty/invalid numbers keep the last good value.
