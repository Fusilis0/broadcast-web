# Library

Left rail **Race setup → Library**. Browse textures and meshes you **attach** to sponsors, plates, and similar. It does **not** hide scene objects — that is [Assets](./assets.md).

---

## Controls

| Control | What it does |
| --- | --- |
| **Refresh** | Reload the library list |
| **Upload…** | Pick `.png` `.jpg` `.webp` `.glb` `.gltf` |

Upload is shown only when `projectsApiBase` is set **and** role is not **air**. Without API, the panel still lists committed files under `public/assets/library` (hint on the panel).

From Assets or World Details, **Library…** opens a picker: choose an image, **Solid plate**, or **Cancel**.

---

## What it is not

- Not the boat name catalogue
- Not Cesium ion / hero glTFs
- Not Fleet add-boat
