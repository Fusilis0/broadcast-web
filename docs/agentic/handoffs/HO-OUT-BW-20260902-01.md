**OBS still open for 3D only** after OUT-06 (worker could not run OBS). AR/2D were Pass before OUT-06.

**Not the mouse feature.** Nobody added a “boost fps on mousedown.” Click/hover almost certainly **wakes Chromium compositor / rAF**. Desktop already sets `backgroundThrottling: false`; `STUDIO_TICK_FPS = 60` is a **main-process** interval. Preview is **rAF**. NDI pumps are **`studio:tick`**.

## Why OUT-06 can make idle *worse*
GPU UYVY pack (half-width RT + skip CPU pack) was cheaper on the renderer thread. It was also the **stripe** path. Live 3D now does a **1080p CPU UYVY pack every send** (same class as working AR UYVA). That can hitch the JS thread so **idle preview looks ~8** while **input-driven rAF** still paints extra frames (operator sees >40 while clicking).
